# Ricardo Piano Studio

Landing page para Ricardo Piano Studio construida con React + Vite.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Instalar

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

Luego abre la dirección que muestre Vite, normalmente:

http://localhost:5173

## Crear versión de producción

```bash
npm run build
```

## Abrir en VS Code

Desde la carpeta del proyecto:

```bash
code .
```

## Próximos cambios recomendados

1. Sustituir los placeholders de imágenes por fotografías reales.
2. Cambiar `WHATSAPP_URL` en `src/App.jsx` por el número real.
3. Ajustar textos y testimonios.
4. Añadir favicon y logotipo definitivo.
5. Conectar el CTA con WhatsApp.
